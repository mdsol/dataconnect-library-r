# Supported Date and Time Formats

**Format token reference:**

| Token | Description |
|-------|-------------|
| `yyyy` | 4-digit year |
| `yy` | 2-digit year |
| `MM` | 2-digit numeric month |
| `MMM` | Abbreviated month name (e.g., `Jan`, `Feb`) |
| `dd` | 2-digit day of month |
| `HH` | Hour (24-hour clock) |
| `mm` | Minutes |
| `ss` | Seconds |
| `SSS` | Milliseconds |
